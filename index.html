참나무 고목 지도

사슴벌레 · 장수풍뎅이 채집을 위한 참나무 서식지 지도

이 지도는 산림청이 공개한 공식 임상도(1~9영급) 데이터를 기반으로, 전국의 참나무류(상수리나무·굴참나무 등) 서식 구역을 위성지도 위에 시각화한 웹 도구입니다. 참나무 노령림이 어디에 분포하는지 한눈에 확인할 수 있어, 사슴벌레와 장수풍뎅이 채집 장소를 미리 계획하는 데 도움을 드리고자 만들었습니다.

주요 기능

  • 영급(수령)·수종 계열별 색상 구분 표시 및 세부 필터
  • 키워드 장소 검색과 카카오 로드뷰 확인 (숲 폴리곤 미니맵 포함)
  • 관심 장소를 별·동그라미·자동차 아이콘으로 저장하고 폴더로 정리
  • 실시간 GPS 위치 추적 및 이동 방향 표시
  • 기상청 실측 데이터 기반 실시간 기온·하늘상태 표시
  • 저장한 두 장소를 출발/도착으로 지정해 카카오맵 자동차 길찾기 연동
  • 구글 계정 로그인 시 여러 기기 간 저장 장소 동기화
