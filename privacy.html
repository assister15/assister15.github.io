개인정보처리방침

시행일: 2026년 10월 8일

참나무 고목 지도(이하 "이 사이트")는 회원가입 없이 쓸 수 있는 무료 웹 지도입니다. 이 방침은 이 사이트와 지도(https://assister15.github.io/chamnamu-gomok/)를 이용할 때 어떤 정보가 어디에 저장되고 어디로 전달되는지 설명합니다.

1. 운영자가 수집하는 정보

이 사이트는 별도의 서버나 회원 데이터베이스를 운영하지 않으며, 이름·연락처 같은 개인정보를 운영자가 직접 수집하거나 저장하지 않습니다. 접속 통계나 분석 도구도 사용하지 않습니다. 다만 이 사이트는 GitHub Pages로 제공되므로, 접속 시 GitHub가 서비스 운영을 위해 접속 기록(IP 주소 등)을 처리할 수 있습니다.

2. 이용자 기기에 저장되는 정보

다음 정보는 이용자의 브라우저(기기) 안에만 저장되며 운영자에게 전송되지 않습니다.

  • 저장한 장소와 폴더, 저장 목록의 순서와 패널 크기 설정
  • 최근 검색어와 지도 화면 위치
  • 손으로 그린 경로, 위치 추적으로 남긴 지나간 길, 그리기 색상·굵기 설정

브라우저의 사이트 데이터를 삭제하면 이 정보도 함께 삭제됩니다.

3. 위치정보

'내 위치' 버튼이나 실시간 위치 추적을 이용자가 직접 켰을 때만 브라우저가 위치 사용 권한을 요청하며, 허용하지 않으면 위치정보는 사용되지 않습니다. 위치는 지도에 내 위치를 표시하는 데 쓰이고 운영자 서버로 전송·저장되지 않습니다. 다만 날씨와 고도 정보를 보여 주기 위해 지도 화면의 중심이나 선택한 지점의 좌표가 아래 5항의 외부 서비스로 전달됩니다.

4. 구글 로그인과 구글 드라이브 동기화

로그인은 이용자가 로그인 버튼을 눌렀을 때만 이루어지며, 로그인하지 않아도 지도의 모든 기능은 그 기기 안에서 그대로 쓸 수 있습니다. 로그인하면 구글 드라이브의 '앱 전용 숨김 저장 공간'(drive.appdata 권한)에 저장 장소와 폴더 정보(삭제 기록 포함)를 담은 파일 하나만 만들어 읽고 쓰며, 이는 여러 기기에서 같은 목록을 쓰기 위한 용도입니다. 이 권한으로는 이용자의 다른 드라이브 파일에 접근할 수 없습니다. 지나간 길과 손그림 경로는 동기화에 포함되지 않습니다. 로그아웃해도 기기에 저장된 정보는 유지됩니다.

연결을 완전히 끊으려면 구글 계정 설정의 보안 메뉴에서 이 앱에 부여한 접근 권한을 해제하면 됩니다. 지도 화면을 열면 로그인 기능을 위해 구글의 스크립트가 함께 불러와집니다.

5. 외부 서비스로 전달되는 정보

이 사이트는 다음 외부 서비스를 이용하며, 서비스를 제공하는 과정에서 각 사업자가 접속 정보(IP 주소, 기기·브라우저 정보 등)를 처리할 수 있습니다. 각 서비스의 정책은 해당 사업자의 방침을 따릅니다.

  • 카카오맵 API — 지도 표시, 장소 검색, 로드뷰, 좌표의 주소 변환
  • 기상청 단기예보 공공데이터(공공데이터포털) — 현재 기온과 하늘 상태 조회. 지도 위치를 기상청 격자 좌표로 바꿔 요청합니다.
  • Open-Meteo, Open-Elevation, Open Topo Data — 선택한 지점의 고도 조회. 해당 지점의 위도·경도가 전달됩니다.
  • 구글(로그인, 드라이브, 애드센스) — 위 4항과 아래 6항 참조
  • 카카오맵 길찾기 링크 — 이용자가 '카카오맵으로 길찾기'를 눌렀을 때만 카카오맵으로 이동하며, 출발·도착 좌표가 그 주소에 담겨 전달됩니다.

6. 광고와 쿠키

이 사이트는 구글 애드센스 광고를 게재할 수 있습니다(승인 여부와 시점에 따라 광고가 보이지 않을 수 있습니다). 구글과 그 광고 파트너는 쿠키를 사용해 이용자의 이전 방문 기록을 바탕으로 광고를 보여 줄 수 있습니다. 이용자는 구글 광고 설정에서 맞춤 광고를 끌 수 있으며, 구글이 광고 서비스에서 정보를 이용하는 방식은 구글 정책 안내에서 확인할 수 있습니다.

7. 아동의 개인정보

이 사이트는 만 14세 미만 아동의 개인정보를 별도로 수집하지 않습니다.

8. 방침의 변경

기능이 추가되거나 이용하는 서비스가 바뀌면 이 방침을 고치고 위의 시행일을 갱신합니다.
